# Vim 编辑器完全指南

> 学习目标：看完后能在 Linux 服务器中熟练使用 Vim 修改代码/配置文件，能回答 Vim/Vi、模式切换、保存退出、查找替换、批量编辑、配置文件、插件等企业面试高频问题。

## 00 本章学习路线与面试重点

### 0.1 一句话理解 Vim

Vim 是 Linux/Unix 世界中最常用的终端文本编辑器之一，核心特点是“多模式编辑”：普通文本编辑器通常直接输入文字，而 Vim 把“移动光标、删除复制、输入文字、保存退出、查找替换”等操作拆成不同模式，因此熟练后效率很高。

### 0.2 学习主线

记住这条主线即可：`打开文件 → 默认进入命令模式 → 按 i/a/o 进入插入模式写内容 → Esc 回到命令模式 → : 进入末行模式 → :wq 保存退出`。

### 0.3 面试最爱问什么

面试常问：`Vi 和 Vim 区别`、`Vim 三种模式`、`如何保存退出/强制退出`、`如何查找替换`、`如何复制/删除/粘贴多行`、`如何显示行号`、`如何跳转指定行`、`如何处理只读文件/乱码/交换文件`、`vimrc 配置在哪`。

### 0.4 零基础先背这 15 个命令

| 场景         | 命令            | 说明                                             |
| ------------ | --------------- | ------------------------------------------------ |
| 打开文件     | `vim file.txt`  | 打开已有文件；没有则新建缓冲区，保存后才真正落盘 |
| 进入编辑     | `i`             | 在光标前插入文本                                 |
| 回到命令模式 | `Esc`           | 万能“复位键”，不知道在哪个模式先按它             |
| 保存         | `:w`            | write，保存不退出                                |
| 保存退出     | `:wq` / `ZZ`    | 保存并退出                                       |
| 不保存退出   | `:q!`           | 放弃修改强制退出                                 |
| 显示行号     | `:set nu`       | number，显示行号                                 |
| 跳到第 n 行  | `nG` 或 `:n`    | 如 `50G` 或 `:50`                                |
| 删除一行     | `dd`            | 删除当前行，本质上放入 Vim 寄存器，可再粘贴      |
| 复制一行     | `yy`            | yank 当前行                                      |
| 粘贴         | `p` / `P`       | 粘贴到后面/下面；粘贴到前面/上面                 |
| 撤销         | `u`             | undo                                             |
| 反撤销       | `Ctrl+r`        | redo                                             |
| 查找         | `/关键字`       | 向下查找，`n/N` 跳下一个/上一个                  |
| 全局替换     | `:%s/old/new/g` | 整个文件替换 old 为 new                          |

## 01 Linux 编辑器与 Vim 使用概述

### 1.1 Linux 中常见文本编辑工具

Linux 上常见编辑方式：`cat` 适合快速查看/少量重定向写入，不适合交互编辑；`nano` 简单易上手，适合临时修改；`vi` 几乎所有 Unix/Linux 都自带，适合救急；`vim` 是 Vi improved，功能更强，适合开发、运维、服务器配置；`emacs` 功能极强但学习成本也高。

### 1.2 Vim 是什么

Vim 全称 `Vi IMproved`，可以理解为 Vi 的增强版；它兼容 Vi 的基本命令，并增加语法高亮、多级撤销、可视化模式、分屏、多文件编辑、插件扩展、正则查找替换、自动缩进等能力。

### 1.3 Vi 和 Vim 的核心区别

| 对比项     | Vi                         | Vim                                               |
| ---------- | -------------------------- | ------------------------------------------------- |
| 定位       | Unix 早期经典编辑器        | Vi 的增强版本                                     |
| 兼容性     | 几乎所有 Unix/Linux 默认有 | 大多数 Linux 可安装，有些系统默认已装             |
| 语法高亮   | 通常不支持或支持弱         | 支持 C/C++/Shell/Python/配置文件等语法高亮        |
| 撤销能力   | 传统 Vi 撤销能力有限       | 支持多级撤销和反撤销                              |
| 可视化编辑 | 较弱                       | 支持字符选择、行选择、块选择                      |
| 插件系统   | 基本没有                   | 插件生态丰富，可扩展文件树、补全、语法检查等      |
| 实际使用   | 服务器救急、兼容场景       | 日常开发/配置修改/远程运维更常用                  |
| 面试回答   | Vi 是基础版，Vim 是增强版  | Vim 兼容 Vi，并增强高亮、撤销、可视化、插件等能力 |

### 1.4 Vim 安装与版本检查

CentOS/RHEL 7 常用：`sudo yum install -y vim`；CentOS/RHEL 8+/Fedora 常用：`sudo dnf install -y vim`；Ubuntu/Debian 常用：`sudo apt update && sudo apt install -y vim`；安装后检查：`vim --version`；查看命令位置：`which vim`；查看是否为别名：`alias vi`。

```bash
# CentOS / RHEL 7
sudo yum install -y vim

# CentOS / RHEL 8+ / Fedora
sudo dnf install -y vim

# Ubuntu / Debian
sudo apt update
sudo apt install -y vim

# 验证
vim --version
which vim
```

### 1.5 Vim 的适用场景

Vim 适合：远程 SSH 登录服务器修改配置文件，如 `/etc/ssh/sshd_config`、`nginx.conf`；在无图形界面的 Linux 服务器中编辑脚本；快速查找替换日志或配置；临时修改 C/C++/Python/Shell 代码；救援模式下修复系统配置。Vim 不适合：完全不熟悉命令时编辑重要生产文件；需要复杂项目管理且本地有 IDE 时长期大规模开发。

### 1.6 零基础易错点

不要把 `cat` 当编辑器；不要以为进入 Vim 就能直接输入，Vim 默认是命令模式；不要用 `Ctrl+C` 当退出，退出通常是 `Esc` 后输入 `:q`、`:wq` 或 `:q!`；不要在生产服务器上随便 `:wq!`，强制写入可能覆盖重要配置。

### 1.7 本节面试题

**题 1：Vi 和 Vim 有什么区别？**  
答：Vi 是 Unix/Linux 经典文本编辑器，Vim 是 Vi improved，兼容 Vi 基本命令，同时增强了语法高亮、多级撤销、可视化模式、插件扩展、代码折叠、正则搜索替换等能力。生产环境中 Vi 更偏“保底可用”，Vim 更偏“高效开发和运维”。

**题 2：服务器上为什么很多人会用 Vim，而不是只用 VS Code？**  
答：因为服务器常通过 SSH 远程连接，没有图形界面或不方便传文件；Vim 直接在终端运行，启动快、依赖少、能快速修改配置和脚本，适合运维和线上排障。

**题 3：`vim --version` 有什么用？**  
答：可以确认 Vim 是否安装、版本号、编译特性，例如是否支持 `+clipboard`、`+python3`、`+syntax`，这些会影响系统剪贴板、插件、语法高亮等功能。

## 02 Vim 的模式体系

### 2.1 为什么 Vim 要分模式

Vim 的设计理念是“编辑文本不仅是输入文字，还包括大量移动、删除、复制、替换、查找、跳转操作”。所以 Vim 把不同操作放进不同模式：命令模式负责操作，插入模式负责输入，末行模式负责保存退出和批量命令。

### 2.2 三种核心模式总览

| 模式     | 英文                          | 进入方式                                | 主要作用                               | 典型命令                        |
| -------- | ----------------------------- | --------------------------------------- | -------------------------------------- | ------------------------------- |
| 命令模式 | Normal mode                   | 打开文件默认进入；其他模式按 `Esc` 返回 | 移动光标、删除、复制、粘贴、撤销、跳转 | `h/j/k/l`、`dd`、`yy`、`p`、`u` |
| 插入模式 | Insert mode                   | 命令模式按 `i/a/o/I/A/O`                | 像普通编辑器一样输入文字               | 直接输入文本                    |
| 末行模式 | Last line / Command-line mode | 命令模式按 `:`、`/`、`?`                | 保存退出、查找替换、设置、执行命令     | `:wq`、`:set nu`、`:%s/a/b/g`   |

### 2.3 命令模式（Normal mode）

命令模式是 Vim 的默认模式，也是最高频模式；在这里按键不会直接变成文本，而是被解释成命令。例如 `j` 是向下移动，`dd` 是删除当前行，`yy` 是复制当前行，`p` 是粘贴，`u` 是撤销。面试中要强调：Vim 的核心效率来自命令模式，很多操作可以用“数字 + 命令”组合，例如 `5dd` 删除 5 行，`3yy` 复制 3 行。

### 2.4 插入模式（Insert mode）

插入模式用于真正输入文本；进入后底部一般显示 `-- INSERT --`。常用进入方式：`i` 在光标前插入；`a` 在光标后追加；`o` 在当前行下方新开一行；`I` 到行首插入；`A` 到行尾追加；`O` 在当前行上方新开一行。插入结束后按 `Esc` 回命令模式。

### 2.5 末行模式（Last line mode）

末行模式也叫命令行模式，按 `:` 进入，用于输入以冒号开头的命令，例如 `:w` 保存，`:q` 退出，`:wq` 保存退出，`:set nu` 显示行号，`:3,8s/old/new/g` 替换第 3 到 8 行内容。按 `/` 或 `?` 也会进入命令行输入状态，用于向下/向上查找。

### 2.6 模式切换逻辑

```text
打开文件后默认：命令模式
命令模式 -- i/a/o/I/A/O --> 插入模式
插入模式 -- Esc --> 命令模式
命令模式 -- : --> 末行模式
末行模式 -- Enter执行 或 Esc取消 --> 命令模式
```

实战口诀：`想输入按 i，想操作按 Esc，想保存退出按 :`。

### 2.7 其他常见模式（了解但面试可加分）

| 模式                    | 进入方式        | 作用                                |
| ----------------------- | --------------- | ----------------------------------- |
| 可视模式 Visual         | `v`             | 按字符选择文本，再复制/删除/缩进    |
| 可视行模式 Visual Line  | `V`             | 按整行选择文本                      |
| 可视块模式 Visual Block | `Ctrl+v`        | 按矩形块选择，适合多行列编辑        |
| 替换模式 Replace        | `R`             | 输入字符会覆盖原字符，按 `Esc` 退出 |
| 选择模式 Select         | `gh/gH/gCtrl+h` | 类似普通编辑器选择，使用较少        |

### 2.8 本节面试题

**题 1：Vim 有哪几种核心模式？如何切换？**  
答：核心是命令模式、插入模式、末行模式。打开文件默认命令模式；命令模式按 `i/a/o` 进入插入模式；插入模式按 `Esc` 回命令模式；命令模式按 `:` 进入末行模式；末行命令执行或取消后回到命令模式。

**题 2：为什么按键盘输入不了文字，反而光标乱动？**  
答：因为当前处于命令模式，按键被当作命令执行了。应按 `i` 进入插入模式后再输入；如果状态混乱，先按 `Esc` 回命令模式，再按 `i`。

**题 3：命令模式和末行模式有什么区别？**  
答：命令模式主要执行单键或组合键编辑操作，如移动、删除、复制、粘贴；末行模式输入冒号命令，主要做保存退出、查找替换、设置选项、多文件编辑等更全局的操作。

## 03 Vim 的基本操作流程

### 3.1 打开文件

基本语法：`vim 文件名`；文件存在则打开，不存在则创建一个新缓冲区，只有执行 `:w` 后才会真正创建文件。

```bash
vim test.txt        # 打开或新建 test.txt
vim +10 test.txt    # 打开后跳到第 10 行
vim + test.txt      # 打开后跳到最后一行
vim +/main test.c   # 打开后跳到第一个匹配 main 的位置
vim -R file.txt     # 只读方式打开，类似 view file.txt
vim a.txt b.txt     # 同时打开多个文件
```

### 3.2 新建并编辑文件

操作流程：`vim hello.txt` → 按 `i` → 输入内容 → 按 `Esc` → 输入 `:wq` → 回车。注意：没保存前，文件可能还没真正写到磁盘。

### 3.3 命令模式进入插入模式的常用方式

| 命令 | 作用                         | 例子                             |
| ---- | ---------------------------- | -------------------------------- |
| `i`  | 在光标前插入                 | 最常用，开始写文本               |
| `a`  | 在光标后追加                 | 光标在某字符上，想从它后面继续写 |
| `o`  | 在当前行下方新开一行         | 写代码时新增下一行               |
| `I`  | 到当前行第一个非空字符前插入 | 快速在行首补内容                 |
| `A`  | 到当前行末尾追加             | 快速补行尾注释/分号              |
| `O`  | 在当前行上方新开一行         | 在当前代码前插入一行             |

### 3.4 保存与退出

| 命令              | 含义                               | 使用场景                       |
| ----------------- | ---------------------------------- | ------------------------------ |
| `:w`              | 保存，不退出                       | 写配置文件时随手保存           |
| `:q`              | 退出                               | 文件未修改或已保存             |
| `:wq`             | 保存并退出                         | 最常用                         |
| `:x`              | 保存并退出，但无修改时不更新时间戳 | 比 `:wq` 更精细                |
| `ZZ`              | 保存并退出，不需要冒号             | 命令模式快捷键，注意大写       |
| `:q!`             | 不保存强制退出                     | 修改错了，放弃全部修改         |
| `:w!`             | 强制保存                           | 文件只读但当前用户有权限时使用 |
| `:w new.txt`      | 另存为                             | 保留原文件，写到新文件         |
| `:saveas new.txt` | 另存为并切换当前编辑文件为新文件   | 后续编辑对象变成新文件         |

### 3.5 放弃修改与恢复文件

如果只想退出不保存：`Esc` → `:q!`。如果想撤销最近一步：命令模式按 `u`。如果想撤销多步：`3u`。如果撤销错了：`Ctrl+r` 恢复。若想重新从磁盘加载文件、放弃当前所有未保存修改：`:e!`。

### 3.6 只读文件保存失败怎么办

常见错误：`E45: 'readonly' option is set` 或权限不足。解决思路：如果只是误打开，`:q!` 退出；如果有权限但 Vim 标记只读，尝试 `:w!`；如果当前用户无写权限，不能靠 Vim 魔法绕过，需要用 `sudo` 重新打开：`sudo vim 文件名`。已经编辑了很多内容不想丢，可尝试 `:w !sudo tee %`，含义是把当前缓冲区内容通过 `sudo tee` 写回当前文件。

### 3.7 本节面试题

**题 1：如何用 Vim 打开文件并跳到第 100 行？**  
答：命令行可用 `vim +100 file.txt`；已进入 Vim 后可在命令模式按 `100G`，或末行模式输入 `:100`。

**题 2：`:wq`、`:q!`、`:x` 有什么区别？**  
答：`:wq` 保存并退出；`:q!` 放弃修改强制退出；`:x` 也是保存退出，但只有文件有改动时才写入磁盘，因此无改动时不会更新时间戳。

**题 3：生产服务器上改配置文件时，怎样更安全？**  
答：先备份，如 `cp nginx.conf nginx.conf.bak`；编辑时用 `:set nu` 显示行号；保存前检查关键配置；必要时使用服务自带检查命令，如 `nginx -t`；不要随便强制保存系统文件。

## 04 Vim 正常模式命令集

### 4.1 正常模式命令的组合规律

Vim 很多命令遵循：`数字 + 操作 + 范围`。例如 `5dd` 表示删除 5 行；`3w` 表示向后移动 3 个单词；`d$` 表示删除到行尾；`yG` 表示复制到文件末尾。理解组合规律比死背更重要。

### 4.2 光标基础移动

| 命令 | 作用                      |
| ---- | ------------------------- |
| `h`  | 左移一个字符              |
| `j`  | 下移一行                  |
| `k`  | 上移一行                  |
| `l`  | 右移一个字符              |
| `0`  | 到当前行行首              |
| `^`  | 到当前行第一个非空白字符  |
| `$`  | 到当前行行尾              |
| `n|` | 到当前行第 n 列，如 `20|` |
| `+`  | 到下一行第一个非空白字符  |
| `-`  | 到上一行第一个非空白字符  |

> 零基础理解：`h/j/k/l` 是为了让手不用离开主键盘区域；熟练后比方向键更快，但方向键也能用。

### 4.3 按单词移动

| 命令 | 作用                                   |
| ---- | -------------------------------------- |
| `w`  | 到下一个单词开头                       |
| `e`  | 到当前/下一个单词结尾                  |
| `b`  | 到当前/上一个单词开头                  |
| `W`  | 按“大单词”移动到下一个开头，标点不拆分 |
| `E`  | 按“大单词”移动到结尾                   |
| `B`  | 按“大单词”移动到上一个开头             |

普通单词会把标点当边界，比如 `hello_world()` 可能被拆；大单词按空白分割，更粗粒度。

### 4.4 按屏幕翻页和定位

| 命令     | 作用                         |
| -------- | ---------------------------- |
| `Ctrl+f` | 向下翻一页，forward          |
| `Ctrl+b` | 向上翻一页，backward         |
| `Ctrl+d` | 向下翻半页，down             |
| `Ctrl+u` | 向上翻半页，up               |
| `Ctrl+e` | 屏幕向下滚一行，光标相对不动 |
| `Ctrl+y` | 屏幕向上滚一行，光标相对不动 |
| `H`      | 光标到当前屏幕顶部           |
| `M`      | 光标到当前屏幕中间           |
| `L`      | 光标到当前屏幕底部           |

### 4.5 全局跳转

| 命令     | 作用                                  |
| -------- | ------------------------------------- |
| `gg`     | 到文件第一行                          |
| `G`      | 到文件最后一行                        |
| `nG`     | 到第 n 行，如 `50G`                   |
| `:n`     | 到第 n 行，如 `:50`                   |
| `Ctrl+g` | 显示当前文件名、行号、百分比等信息    |
| `%`      | 在成对括号间跳转，如 `()`、`[]`、`{}` |
| `''`     | 回到上一次跳转前位置                  |
| `'.`     | 到上次修改位置                        |

### 4.6 删除命令

| 命令        | 作用                             |
| ----------- | -------------------------------- |
| `x`         | 删除光标所在字符                 |
| `X`         | 删除光标左侧字符                 |
| `nx`        | 删除光标处开始 n 个字符，如 `3x` |
| `dd`        | 删除当前整行                     |
| `ndd`       | 删除 n 行，如 `5dd`              |
| `D` 或 `d$` | 删除到行尾                       |
| `d^`        | 删除到行首第一个非空字符附近     |
| `dw`        | 删除到下一个单词开头             |
| `de`        | 删除到当前/下一个单词结尾        |
| `dG`        | 删除当前行到文件末尾             |
| `dgg`       | 删除当前行到文件开头             |

重要细节：Vim 中删除通常相当于“剪切”，删除内容会进入寄存器，所以可以用 `p` 粘贴回来。误删后立刻按 `u` 撤销。

### 4.7 修改/替换命令

| 命令        | 作用                                           |
| ----------- | ---------------------------------------------- |
| `r字符`     | 替换当前一个字符，替换后仍在命令模式           |
| `R`         | 进入连续替换模式，输入会覆盖原字符，`Esc` 退出 |
| `cw`        | 修改从光标到单词末尾，之后进入插入模式         |
| `cc`        | 修改当前整行，之后进入插入模式                 |
| `C` 或 `c$` | 修改从光标到行尾                               |
| `s`         | 删除当前字符并进入插入模式                     |
| `S`         | 删除当前行并进入插入模式                       |
| `~`         | 切换当前字符大小写                             |

### 4.8 复制与粘贴

| 命令  | 作用                          |
| ----- | ----------------------------- |
| `yy`  | 复制当前行                    |
| `nyy` | 复制 n 行，如 `3yy`           |
| `yw`  | 复制从光标到单词末尾/下个边界 |
| `y$`  | 复制到行尾                    |
| `y^`  | 复制到行首有效字符附近        |
| `yG`  | 复制当前行到文件末尾          |
| `ygg` | 复制当前行到文件开头          |
| `p`   | 粘贴到光标后/当前行下方       |
| `P`   | 粘贴到光标前/当前行上方       |

实战例子：复制第 10 到 20 行可输入 `:10,20y`，然后移动到目标位置按 `p`。复制 5 行并粘贴：`5yy` → 移动位置 → `p`。

### 4.9 撤销、反撤销、重复

| 命令          | 作用                      |
| ------------- | ------------------------- |
| `u`           | 撤销上一步                |
| `nu`          | 撤销 n 步，如 `3u`        |
| `Ctrl+r`      | 反撤销                    |
| `U`           | 撤销当前行的所有修改      |
| `.`           | 重复上一次修改类操作      |
| `:earlier 5m` | 回到 5 分钟前的编辑状态   |
| `:later 5m`   | 回到之后 5 分钟的编辑状态 |

`.` 是 Vim 进阶效率核心：例如你刚执行 `dw` 删除一个单词，之后移动到另一个位置按 `.`，会重复删除单词操作。

### 4.10 缩进、合并、格式化

| 命令  | 作用                  |
| ----- | --------------------- |
| `>>`  | 当前行右缩进          |
| `<<`  | 当前行左缩进          |
| `n>>` | 当前行开始 n 行右缩进 |
| `n<<` | 当前行开始 n 行左缩进 |
| `==`  | 自动调整当前行缩进    |
| `n==` | 自动调整 n 行缩进     |
| `J`   | 合并当前行和下一行    |

### 4.11 本节面试题

**题 1：删除当前行、删除 10 行、删除到行尾分别怎么做？**  
答：当前行 `dd`；从当前行开始删除 10 行 `10dd`；删除到行尾 `D` 或 `d$`。

**题 2：Vim 中删除和复制后的内容能不能粘贴？**  
答：能。Vim 的删除通常会把文本放进寄存器，相当于剪切；复制用 `y`，删除用 `d`，粘贴用 `p/P`。

**题 3：如何快速复制 5 行并粘贴到当前位置下方？**  
答：命令模式下 `5yy` 复制当前行及下面 4 行，移动到目标位置后按 `p` 粘贴到下方。

**题 4：`u` 和 `Ctrl+r` 的区别？**  
答：`u` 是撤销上一步操作；`Ctrl+r` 是反撤销，用于恢复刚才被撤销的操作。

## 06 可视模式与批量编辑补充

### 6.1 可视模式是什么

可视模式用于“先选中文本，再执行操作”。普通模式下很多命令是先输入操作再指定范围，如 `d$`；可视模式则是先用 `v/V/Ctrl+v` 选择范围，再按 `d/y/c/>/<` 等操作。

### 6.2 三种可视模式

| 命令     | 模式         | 作用                              |
| -------- | ------------ | --------------------------------- |
| `v`      | 字符可视模式 | 按字符选择，适合选一段文本        |
| `V`      | 行可视模式   | 按整行选择，适合批量复制/删除多行 |
| `Ctrl+v` | 块可视模式   | 按矩形区域选择，适合多行列操作    |

### 6.3 可视模式常用操作

选中后按 `y` 复制；按 `d` 删除；按 `c` 修改并进入插入模式；按 `>` 右缩进；按 `<` 左缩进；按 `=` 自动缩进；按 `u` 转小写；按 `U` 转大写。

### 6.4 块编辑实战：给多行开头添加注释

步骤：移动到第一行注释位置 → 按 `Ctrl+v` → 用 `j/k` 选择多行同一列 → 按 `I` → 输入 `//` 或 `#` → 按 `Esc`，Vim 会把内容插入到所有选中行。

### 6.5 本节面试题

**题 1：Vim 如何批量注释多行？**  
答：可用块可视模式：`Ctrl+v` 选择多行开头列，按 `I` 输入注释符，如 `#` 或 `//`，再按 `Esc` 应用到多行；如果装了 `vim-commentary`，可选中后按 `gc` 注释。

**题 2：`v`、`V`、`Ctrl+v` 有什么区别？**  
答：`v` 是字符选择，`V` 是整行选择，`Ctrl+v` 是矩形块选择，适合列编辑。

## 08 Vim 配置：vimrc 从基础到实用

### 8.1 配置文件位置

用户级配置：`~/.vimrc`，只影响当前用户，最常用；系统级配置：`/etc/vimrc` 或 `/etc/vim/vimrc`，影响所有用户，通常需要 root 权限；Windows GVim 通常使用 `_vimrc`。面试回答建议：日常优先改 `~/.vimrc`，避免影响其他用户。

### 8.2 创建和编辑配置文件

```bash
vim ~/.vimrc
```

### 8.3 常用基础配置模板

```vim
" ========== 基础显示 ==========
set number              " 显示行号
set relativenumber      " 显示相对行号，可选
syntax on               " 开启语法高亮
set cursorline          " 高亮当前行
set showmode            " 显示当前模式
set showcmd             " 显示正在输入的命令
set laststatus=2        " 始终显示状态栏
set wildmenu            " 命令补全菜单

" ========== 缩进与 Tab ==========
set autoindent          " 自动缩进
set smartindent         " 智能缩进
set tabstop=4           " Tab 显示宽度为 4
set shiftwidth=4        " 自动缩进宽度为 4
set softtabstop=4       " 按 Tab 插入 4 个空格宽度
set expandtab           " Tab 转空格，团队协作更稳定

" ========== 查找 ==========
set hlsearch            " 高亮搜索结果
set incsearch           " 输入时实时搜索
set ignorecase          " 搜索忽略大小写
set smartcase           " 搜索包含大写时自动区分大小写

" ========== 显示与滚动 ==========
set wrap                " 长行自动换行显示
set linebreak           " 按单词边界换行
set scrolloff=5         " 光标上下保留 5 行上下文
set mouse=a             " 开启鼠标支持

" ========== 编码 ==========
set encoding=utf-8
set fileencoding=utf-8

" ========== 备份与持久撤销 ==========
set backup
set backupdir=~/.vim/backup//
set undofile
set undodir=~/.vim/undo//
```

### 8.4 配置目录创建

如果配置了备份目录和撤销目录，需要手动创建：

```bash
mkdir -p ~/.vim/backup ~/.vim/undo
```

### 8.5 配置生效方式

方式 1：退出 Vim 后重新打开；方式 2：在 Vim 中执行 `:source ~/.vimrc` 立即加载；方式 3：检查某选项值，如 `:set number?`、`:set tabstop?`。

### 8.6 常用配置解释

`set number` 方便定位报错行；`set expandtab` 避免 Tab 在不同编辑器宽度不一致；`set shiftwidth=4` 控制缩进层级；`set ignorecase smartcase` 让搜索更智能；`set undofile` 让文件关闭后再次打开仍可撤销历史；`set mouse=a` 方便新手选择和滚动，但在某些终端复制时可能需要临时关闭 `:set mouse=`。

### 8.7 本节面试题

**题 1：Vim 的用户配置文件一般在哪？**  
答：Linux 下通常是 `~/.vimrc`，只影响当前用户；系统级配置可能在 `/etc/vimrc` 或 `/etc/vim/vimrc`，影响所有用户。

**题 2：如何永久显示行号？**  
答：在 `~/.vimrc` 中加入 `set number`，保存后重启 Vim 或执行 `:source ~/.vimrc`。

**题 3：`tabstop`、`shiftwidth`、`expandtab` 分别是什么？**  
答：`tabstop` 控制 Tab 显示宽度；`shiftwidth` 控制自动缩进宽度；`expandtab` 表示按 Tab 时插入空格而不是 Tab 字符，常用于团队代码风格统一。

## 09 Vim 插件配置：Vim-Plug 与常用插件

### 9.1 插件适合什么场景

插件适合本地开发环境或个人服务器，提高效率；生产服务器上不建议装过多插件，因为插件可能带来依赖、下载、启动速度、安全和稳定性问题。面试回答要体现工程意识：开发机可增强，生产机保持简洁。

### 9.2 安装 Vim-Plug（Linux/macOS）

```bash
curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

如果 GitHub 网络不稳定，可使用可信镜像源；但企业环境中应优先遵守公司内网镜像规范。

### 9.3 验证 Vim-Plug

打开 Vim 后执行：

```vim
:PlugStatus
```

如果不是编辑器命令，说明 `plug.vim` 没装到正确目录，或当前 Vim 没加载对应 autoload 文件。

### 9.4 插件配置模板

```vim
" ========== Vim-Plug ==========
call plug#begin('~/.vim/plugged')

" 文件管理器：目录树
Plug 'preservim/nerdtree'

" 快速注释
Plug 'tpope/vim-commentary'

" 代码片段
Plug 'SirVer/ultisnips'
Plug 'honza/vim-snippets'

" 异步语法检查
Plug 'dense-analysis/ale'

" 快速跳转
Plug 'easymotion/vim-easymotion'

call plug#end()

" ========== NERDTree ==========
map <F3> :NERDTreeToggle<CR>
let g:NERDTreeShowHidden=1

" ========== UltiSnips ==========
let g:UltiSnipsExpandTrigger='<tab>'
let g:UltiSnipsJumpForwardTrigger='<c-j>'
let g:UltiSnipsJumpBackwardTrigger='<c-k>'

" ========== ALE ==========
let g:ale_lint_on_save=1
let g:ale_lint_on_text_changed='normal'

" ========== vim-commentary ==========
" gcc 注释/取消注释当前行；可视模式选中后 gc 注释/取消注释
```

### 9.5 安装插件

修改 `~/.vimrc` 后，打开 Vim 执行：

```vim
:PlugInstall
```

### 9.6 插件管理命令

| 命令           | 作用                      |
| -------------- | ------------------------- |
| `:PlugInstall` | 安装新增插件              |
| `:PlugUpdate`  | 更新所有插件              |
| `:PlugUpgrade` | 更新 Vim-Plug 本身        |
| `:PlugClean`   | 清理 vimrc 中已删除的插件 |
| `:PlugStatus`  | 查看插件状态              |

### 9.7 常用插件怎么用

`NERDTree`：按 `<F3>` 打开/关闭文件树；`vim-commentary`：`gcc` 注释当前行，选中多行后 `gc` 批量注释；`UltiSnips + vim-snippets`：输入片段触发词后按 Tab 展开；`ALE`：保存或编辑时提示语法问题；`easymotion`：用快捷键快速跳转到屏幕上的目标位置。

### 9.8 本节面试题

**题 1：Vim 插件管理器有什么用？**  
答：用于统一安装、更新、清理插件，避免手动复制插件文件。常见插件管理器有 Vim-Plug、Vundle、Pathogen 等，其中 Vim-Plug 简洁常用。

**题 2：为什么生产服务器不建议装太多 Vim 插件？**  
答：生产环境强调稳定、安全、可恢复；插件可能引入依赖和启动开销，也可能因网络或版本问题影响编辑器启动。通常开发机增强，生产机保持最小可用。

**题 3：`NERDTree`、`ALE`、`vim-commentary` 分别解决什么问题？**  
答：`NERDTree` 做文件树导航；`ALE` 做异步语法检查；`vim-commentary` 做快速注释/取消注释。

## 10 常见问题与排错

### 10.1 退出不了 Vim

先按 `Esc`，然后根据需求输入：保存退出 `:wq`；不保存退出 `:q!`；只退出 `:q`。如果底部出现 `-- INSERT --`，说明还在插入模式，必须先 `Esc`。

### 10.2 打开文件提示 swap file exists

Vim 会创建交换文件如 `.file.swp` 防止崩溃丢失。若确认没有其他人正在编辑，可选择恢复 `R` 或删除交换文件；生产环境先确认是不是别人正在编辑同一文件，避免覆盖。

### 10.3 中文乱码

检查终端编码和文件编码。Vim 中可执行 `:set encoding?`、`:set fileencoding?`。常用配置：`set encoding=utf-8`、`set fileencoding=utf-8`。如果原文件不是 UTF-8，需要转换时应先备份。

### 10.4 粘贴代码缩进乱

粘贴前执行 `:set paste`，粘贴后执行 `:set nopaste`。原因是 Vim 的自动缩进会对粘贴内容再次缩进，导致格式错乱。

### 10.5 搜索高亮一直不消失

临时取消：`:nohl`；永久关闭高亮：`:set nohlsearch`；如果希望下次搜索继续高亮，推荐用 `:nohl`。

### 10.6 只读文件保存失败

如果是权限不足，退出后用 `sudo vim file`；如果已经修改很多，可尝试 `:w !sudo tee %`。注意这会写回当前文件，需要确认内容正确。

### 10.7 鼠标复制不好用

如果 `.vimrc` 设置了 `set mouse=a`，鼠标选择可能变成 Vim 选择而不是终端复制。可临时执行 `:set mouse=` 关闭鼠标支持，复制后再 `:set mouse=a`。

### 10.8 插件命令不存在

例如 `:PlugInstall` 提示不是编辑器命令，检查 `~/.vim/autoload/plug.vim` 是否存在；检查使用的是 Vim 不是 Vi；检查 `~/.vimrc` 是否写错，如 `call plug#begin()` 拼写错误。

### 10.9 本节面试题

**题 1：Vim 异常退出后出现 `.swp` 文件怎么办？**  
答：先确认没有其他进程正在编辑该文件；如果上次异常退出，可选择恢复；如果确认不需要恢复且无人编辑，再删除 swap 文件。生产环境不要盲删，避免覆盖别人修改。

**题 2：粘贴大段代码格式乱怎么处理？**  
答：粘贴前 `:set paste`，粘贴后 `:set nopaste`，或配置粘贴快捷键。根因是自动缩进影响粘贴内容。

**题 3：Vim 中文乱码可能由什么导致？**  
答：终端编码、Vim 内部编码、文件实际编码不一致。可通过 `:set encoding?` 和 `:set fileencoding?` 查看，并统一为 UTF-8。

## 11 企业高频面试题与解析

### 11.1 基础概念题

**1）Vim 是什么？为什么 Linux 面试常问它？**  
答：Vim 是终端文本编辑器，适合 SSH 远程环境下修改配置、脚本和代码。Linux 后端、运维、测试开发、嵌入式都可能需要在无 GUI 服务器中快速编辑文件，所以是基础能力。

**2）Vim 默认进入什么模式？**  
答：默认进入命令模式，不是插入模式。要输入文本需要按 `i/a/o`。

**3）如何判断自己处于插入模式？**  
答：底部通常显示 `-- INSERT --`；如果按字母会输入文本，说明在插入模式；如果按 `j/k` 会移动光标，说明在命令模式。

### 11.2 操作命令题

**4）如何删除第 20 到 30 行？**  
答：末行模式输入 `:20,30d`；或者跳到第 20 行后输入 `11dd`。

**5）如何复制第 5 到 10 行到文件末尾？**  
答：`:5,10y` 复制第 5 到 10 行；按 `G` 到文件末尾；按 `p` 粘贴。

**6）如何把当前文件所有 `8080` 替换成 `9090`，并逐个确认？**  
答：`:%s/8080/9090/gc`。

**7）如何快速跳到文件开头、结尾、指定行？**  
答：文件开头 `gg`；文件结尾 `G`；指定行 `nG` 或 `:n`。

**8）如何撤销和恢复撤销？**  
答：撤销 `u`；恢复撤销 `Ctrl+r`。

### 11.3 场景排障题

**9）线上修改 nginx 配置，保存时发现权限不足怎么办？**  
答：最好退出后用有权限用户重新编辑，如 `sudo vim nginx.conf`；如果已编辑很多内容，可谨慎使用 `:w !sudo tee %` 写回当前文件；保存后还要执行 `nginx -t` 检查配置。

**10）你用 Vim 打开文件后提示有 swap 文件，可能是什么原因？**  
答：可能是上次 Vim 异常退出，也可能是另一个用户/进程正在编辑该文件。应先确认是否有人正在编辑，再决定恢复或删除 swap 文件。

**11）如何在 Vim 里不退出就查看当前目录文件？**  
答：使用 `:!ls`，也可用 `:pwd` 查看当前工作目录。

**12）修改配置前怎样降低风险？**  
答：先备份原文件；打开行号；尽量小范围修改；保存后用服务命令检查配置；必要时保留回滚命令。例如 `cp app.conf app.conf.bak`。

### 11.4 进阶效率题

**13）`dd` 和 `D` 有什么区别？**  
答：`dd` 删除整行；`D` 删除从光标到行尾，相当于 `d$`。

**14）`p` 和 `P` 有什么区别？**  
答：`p` 粘贴到光标后或当前行下方；`P` 粘贴到光标前或当前行上方。复制/删除的是行时表现为上下，字符时表现为前后。

**15）`w/e/b` 分别是什么？**  
答：`w` 到下一个单词开头；`e` 到当前或下一个单词结尾；`b` 到当前或上一个单词开头。

**16）如何进行列编辑？**  
答：用块可视模式 `Ctrl+v`，选择矩形区域后可复制、删除、缩进，也可以按 `I` 在多行同一列前插入内容。

**17）如何查看 Vim 某个命令帮助？**  
答：`:help 命令`，如 `:help dd`、`:help substitute`、`:help vim-modes`。

### 11.5 配置与插件题

**18）如何永久设置显示行号和 4 空格缩进？**  
答：在 `~/.vimrc` 写入：

```vim
set number
set tabstop=4
set shiftwidth=4
set softtabstop=4
set expandtab
```

**19）为什么团队项目常要求 `expandtab`？**  
答：因为不同编辑器/终端对 Tab 显示宽度可能不同，使用空格能保持代码排版一致，减少代码风格冲突。

**20）如果 Vim 插件安装失败，你会怎么排查？**  
答：检查网络；检查 `plug.vim` 是否在 `~/.vim/autoload/`；检查 `.vimrc` 语法；检查 Vim 版本；检查插件依赖，如 Python、Node、编译工具等。

## 12 笔试速查表

### 12.1 保存退出类

```vim
:w      " 保存
:q      " 退出
:wq     " 保存退出
:q!     " 不保存退出
:x      " 有修改才保存退出
:e!     " 放弃修改重新加载
```

### 12.2 移动类

```vim
h j k l     " 左下上右
0 ^ $       " 行首/首个非空字符/行尾
w e b       " 单词移动
gg G nG     " 文件开头/结尾/第 n 行
Ctrl+f/b    " 向下/向上翻页
```

### 12.3 编辑类

```vim
i a o       " 插入/追加/下方新行
dd ndd      " 删除一行/删除 n 行
yy nyy      " 复制一行/复制 n 行
p P         " 后/前粘贴
u Ctrl+r    " 撤销/反撤销
r R cw cc   " 单字符替换/连续替换/改词/改行
```

### 12.4 查找替换类

```vim
/word               " 向下查找
?word               " 向上查找
n N                 " 下一个/上一个
:%s/old/new/g       " 全文替换
:%s/old/new/gc      " 全文替换并确认
:3,8s/old/new/g     " 第 3 到 8 行替换
```

### 12.5 配置类

```vim
:set nu             " 显示行号
:set nonu           " 取消行号
:set paste          " 粘贴模式
:set nopaste        " 取消粘贴模式
:source ~/.vimrc    " 重新加载配置
```

## 13 实战练习

### 13.1 练习 1：新建文件并保存

```bash
vim demo.txt
```

按 `i` 输入三行文字 → 按 `Esc` → 输入 `:wq`。目标：熟悉插入、返回命令模式、保存退出。

### 13.2 练习 2：复制删除粘贴

打开 `demo.txt` → `yy` 复制当前行 → `p` 粘贴 → `dd` 删除一行 → `u` 撤销。目标：掌握最基本的编辑闭环。

### 13.3 练习 3：查找替换

准备文本中多处包含 `old_port=8080`，执行：

```vim
:%s/8080/9090/gc
```

逐个确认替换。目标：理解 `%`、`s`、`g`、`c` 的含义。

### 13.4 练习 4：配置 vimrc

编辑 `~/.vimrc` 加入：

```vim
set number
syntax on
set tabstop=4
set shiftwidth=4
set expandtab
```

执行 `:source ~/.vimrc`。目标：理解临时设置和永久配置的区别。

## 14 本章最终总结

Vim 的核心不是“背很多命令”，而是理解模式：命令模式负责高效操作，插入模式负责输入文本，末行模式负责保存退出和全局命令。面试最常考的是模式切换、保存退出、查找替换、多行复制删除、行号配置、vimrc 位置和线上排错。真正使用时先掌握 `i/Esc/:wq/:q!/dd/yy/p/u//word/:%s/old/new/g`，再逐步练习跳转、分屏、可视块和插件即可。
